# site-vitrine-equipe
Projet collaboratif de réalisation d'un site vitrine

## Organisation du travail

Chaque membre de l'équipe travaille sur **sa propre branche** ; personne ne modifie `main` directement.

👉 **Avant de commencer, lisez le [Guide de l'équipe](GUIDE-EQUIPE.md)** : il explique pas à pas comment récupérer le projet, créer votre branche, envoyer votre travail et proposer une Pull Request.
